# Bank Management System 🏦

A console-based Bank Management Application developed in C++ that simulates core banking operations using Object-Oriented Programming and file handling.

## Features
- 🏧 Create new bank account
- 💰 Deposit money
- 💸 Withdraw money
- 💳 Check account balance
- 👥 Display all accounts
- ❌ Close account
- 🔐 Password protected accounts

## Technologies Used
- Language: C++
- Concepts: OOP, File Handling, Classes, Encapsulation
- Platform: Windows (Console Application)

## OOP Concepts Used
| Concept | Description |
|---------|-------------|
| Class | Account class with all banking operations |
| Encapsulation | Private data members (balance, password) |
| Constructor | Default constructor for Account |
| Methods | deposit(), withdraw(), display() |

## How to Run

### Prerequisites
- g++ compiler (MinGW-W64)

### Compile & Run
```bash
g++ bank.cpp -o bank
bank.exe
```
